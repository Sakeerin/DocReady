- Jev (`jev-1.13.0`) ช่วยเพิ่มความแม่นยำขึ้นจาก Rule Baseline ดั้งเดิม 6.3% โดยมีค่าใช้จ่ายเพียง **$0.000126 ต่อเอกสาร** ($0.126 / 1,000 เอกสาร)
